# LOCK IN ENGLISH v3 — 300語

GitHub Pages用。ZIPを展開し、**フォルダの中身**を既存のリポジトリ直下へ上書きアップロード。

## v3の変更点
- 既存200語をそのまま維持、新しい100語を追加（合計300語）。
- 学習カードの意味表示後に「🔊 例文を聞く」ボタンを追加。単語一覧からも「▶ 例文」で再生可能。
- 単語一覧で下にスクロールすると右下に「↑ TOP」ボタンが表示。タップで先頭へ。
- 完全習得／再学習の切替、左「わかった！」右「わからなかった」は維持。
- 進捗保存キーは変更していません。同じ公開URL・同じ端末／ブラウザなら過去の学習状態を引き継ぐ設計です。

## 注意
- **更新前に設定から進捗JSONをエクスポートしてバックアップしてください。**
- 音声はブラウザ内蔵の英語読み上げ機能を利用。声質・再生の可否はOSとブラウザに依存し、録音されたネイティブ音声ではありません。
- 既存の最初の100語は例文が未登録のため、例文音声ボタンは表示されません。追加した101〜300語は例文付きです。
- PCとiPhoneの学習記録は自動同期されません。
- GitHub Pagesに反映後、表示が古ければブラウザを再読み込みしてください。
