# LOCK IN ENGLISH v2 — 200語
GitHub Pages 用。フォルダの中身をリポジトリ直下にアップロードしてください。

- 既存の100語を残し、新規100語を追加（合計200語）
- 単語一覧で「★ 完全に覚えた」を押すと、その語は総単語数・習得数に残り、今後の出題から除外
- 同じボタンが「↻ 再学習」に変わり、いつでも未習得に戻せる
- 「わかった！」は左、「わからなかった」は右
- 発音記号とブラウザ音声読み上げ、例文（追加100語）
- 以前の進捗は同じ端末・ブラウザで同じ公開URLを使う限り引き継ぎます（保存キーは維持）
- 設定から進捗をエクスポート・インポート可能。端末間の自動同期はありません。

## 更新時の注意
アップロード前に「設定 → 進捗をJSONで保存」でバックアップ推奨。
**GitHub上のファイルを更新しても、ブラウザのlocalStorageに保存された学習記録は通常消えません。**
ただし、URL/ドメイン変更、ブラウザデータ消去、プライベートモードなどで記録が別になったり消える場合があります。
GitHub Pagesで開き、古い表示が残る場合は再読み込みしてください。
