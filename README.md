# LOCK IN ENGLISH — 500語版（v4）

## 更新内容
- 既存の300語を**順序もデータも変更せず**保持し、新規200語を追加（計500語）。
- 新規200語は米語発音記号・意味・英文・例文和訳付き。
- 単語音声、例文音声、一覧の「↑ TOP」、完全習得・再学習、学習進捗の保存を維持。
- 学習記録の保存キー `lock-in-english-basic-v1` は変更していません。同じGitHub PagesのURLと同じブラウザなら通常は引き継がれます。
- 単語データ取得時のキャッシュ回避パラメータを500語版に更新。読み込んだ語数が500でなければエラー表示。

## GitHubへの反映
1. 現在のアプリの「設定」で学習記録をJSONにエクスポートしてバックアップ。
2. ZIPを解凍し、中の7ファイルを**フォルダ構造ごと**既存リポジトリのルートにアップロード。特に `data/words.json` を確認。
3. GitHub Pagesのデプロイ完了後、アプリを再読み込み。総単語数500を確認。
4. 古い表示が残る場合はGitHub上で `data/words.json` に500件あるか確認し、再読み込み。

※学習データは端末・ブラウザごとのlocalStorage保存で、端末間同期はありません。
※音声は端末・ブラウザのWeb Speech APIによる合成音声です。
※IPAは学習用の米語近似表記です。細かな発音の変化や語形ごとの違いは音声と併用してください。
