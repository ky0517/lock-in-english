# LOCK IN ENGLISH — BASIC 001

2030 World Cupを目標にした基礎英単語学習アプリ。初期データは100語です。旧Hamza単語は含まれていません。

## GitHub Pagesへの公開

1. GitHubでリポジトリを作成（例: `lock-in-english`）。
2. このフォルダ内の `index.html`, `style.css`, `app.js`, `manifest.webmanifest`, `icon.svg`, `data/words.json` を **同じフォルダ構造で** アップロード。ZIP自体ではなく中身をアップロードしてください。
3. GitHubの **Settings → Pages → Build and deployment → Deploy from a branch** を選び、`main` / `/(root)` を指定して保存。
4. 表示された公開URLを開いてください。iPhone Safariの共有メニューから「ホーム画面に追加」できます。

## 操作

- 英単語とIPAを確認、発音ボタンで米語音声を再生します（端末の音声合成エンジンを使用）。
- 「意味・例文を見る」を押してから、**左＝わかった！**、**右＝わからなかった**。
- 「わかった！」の次の復習間隔は3日、7日、14日、30日（以後30日）。「わからなかった」は同じセッションの後半に再出題。
- 単語一覧では全100語を確認できます。再学習ボタンで未習得に戻せます。
- 学習記録は `localStorage` に保存され、端末間では自動同期しません。「設定」からJSON形式でバックアップ・移行可能です。
- 学習記録の初期化は「設定」から行えます。

## 注意

- 元のGitHubリポジトリのコードが提供されていないため、これは**独立した置き換え版**です。既存リポジトリへ上書きする前にバックアップしてください。
- `data/words.json` の `example` と `exampleJa` は元データで空欄のため、例文は未収録です。追加するとカードに表示されます。
- 音声はブラウザの `speechSynthesis` を使用。端末や音声エンジンにより品質が異なります。
- IPAは元の100語データに基づきます。多義語・品詞別の発音を完全に網羅する辞書ではありません。
- 学習中にサイトデータを削除すると記録が消えるため、定期的なバックアップを推奨します。
